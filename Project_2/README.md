# 当代人工智能实验二：搜索算法

本项目实现实验二要求的 A*、Minimax 与 Alpha-Beta 剪枝，并附带选做对照实验和运行结果。

## 环境

- Python 3.10 或更高版本
- 仅使用 Python 标准库，无需安装第三方依赖

## 运行必做实验

在 `Project_2` 目录打开终端，运行：

```bash
python experiment2.py
```

程序运行后会在终端显示结果，并将同一份输出写入 `experiment2_results.txt`。内容包括普通迷宫路径、加权地形最小代价、博弈树 Minimax/Alpha-Beta 结果，以及宝藏题的距离矩阵和不同搜索深度的决策。

## 运行选做拓展

```bash
python experiment2_extension.py
```

拓展程序比较 Alpha-Beta 不同子节点访问顺序，并在固定随机种子生成的自设迷宫上对比 `h=0` 与曼哈顿启发。运行后生成或更新：

- `experiment2_extension_results.txt`：实验设置、汇总数据和一张样例迷宫。
- `experiment2_extension_results.csv`：每张自设迷宫的路径长度、扩展节点数和耗时。
- `experiment2_alpha_beta_order.csv`：Minimax 与不同 Alpha-Beta 顺序的搜索统计。

## 实现内容

- **题目一：迷宫寻路**：A* 搜索单位代价最短路径；比较 `h=0` 和曼哈顿距离。
- **题目二：加权地形**：A* 按进入格子的权值计算总代价；按样例规定，进入终点 E 的代价为 0。
- **题目三：博弈树**：实现 Minimax 与 Alpha-Beta，并按从左到右访问子节点。
- **题目四：宝藏分配**：A* 预计算关键位置之间的移动代价，Minimax/Alpha-Beta 在指定深度搜索首选宝藏。
- **选做拓展**：比较节点顺序对 Alpha-Beta 搜索开销的影响，并在多张固定种子迷宫上比较 A* 启发函数。

## 题目四核对结果

按代码中设置的宝藏价值与题目规则，程序输出：

- `H=2`：A 首选 T2，收益差为 `-1`。
- `H=4`：A 首选 T3，收益差为 `3`。

## 复现说明

选做实验使用固定随机种子 `20261109` 至 `20261128` 生成 20 张 `15×15` 迷宫，障碍概率为 `0.24`。Alpha-Beta 顺序对照的博弈树使用固定种子 `20261109`。固定种子使输入可重复生成；运行时间会受电脑和系统负载影响，比较算法开销时应优先参考扩展节点数、访问节点数和剪枝数。
